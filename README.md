# 📌 Overview

**WSO PHP WebShell** is a PHP-based web administration interface designed to demonstrate how server-side webshells can provide an attacker or administrator with an interactive interface after PHP code execution has been obtained.

The project provides a browser-based interface for examining and interacting with a PHP server environment.

It can be useful for studying:

- Webshell architecture
- Post-compromise behavior
- PHP server security
- File-system permissions
- Command execution risks
- Server enumeration
- Web application compromise
- Incident-response detection
- Webshell hunting
- Malware analysis
- CTF environments
